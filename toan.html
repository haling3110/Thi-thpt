1. Hàm số bậc nhất, bậc 2

Khái niệm: Hàm số bậc nhất y = ax + b (a ≠ 0). Hàm số bậc hai y = ax² + bx + c (a ≠ 0) có đồ thị Parabol.

Công thức trọng tâm:

  • Đỉnh Parabol: I(-b/2a ; -Δ/4a) với Δ = b² - 4ac
  • Trục đối xứng: x = -b/2a
  • Sự biến thiên: a > 0 thì bề lõm quay lên trên (giảm trên (-∞; -b/2a), tăng trên (-b/2a; +∞)); a < 0 thì ngược lại.

✏️ Bài tập mẫu & Lời giải: Tìm tọa độ đỉnh và lập bảng biến thiên của y = x² - 4x + 3.
Giải: a = 1, b = -4, c = 3. Hoành độ đỉnh x = -(-4)/(2·1) = 2. Tung độ y = 2² - 4(2) + 3 = -1.
👉 Đỉnh I(2; -1), trục đối xứng x = 2. Do a = 1 > 0 nên hàm số nghịch biến trên (-∞; 2) và đồng biến trên (2; +∞).

2. Phương trình, bất phương trình

Khái niệm: Phương trình bậc hai ax² + bx + c = 0 và Bất phương trình bậc hai ax² + bx + c > 0 (hoặc < 0, ≥ 0, ≤ 0).

Công thức trọng tâm:

  • Định lý Vi-ét: x₁ + x₂ = -b/a và x₁·x₂ = c/a
  • Quy tắc xét dấu tam thức bậc hai: "Trong trái, ngoài cùng" (Giữa 2 nghiệm thì trái dấu với a, ngoài khoảng 2 nghiệm thì cùng dấu với a).

✏️ Bài tập mẫu & Lời giải: Giải bất phương trình x² - 5x + 6 ≤ 0.
Giải: Cho x² - 5x + 6 = 0 ⇔ x = 2 hoặc x = 3.
Hệ số a = 1 > 0. Áp dụng "trong trái ngoài cùng", biểu thức ≤ 0 (lấy dấu âm, tức trái dấu với a) ở trong khoảng 2 nghiệm.
👉 Tập nghiệm S = [2; 3].

3. Hệ phương trình

Khái niệm: Hệ hai phương trình bậc nhất hai ẩn và Hệ phương trình đối xứng (khi thay đổi vai trò x, y thì hệ không đổi).

Phương pháp giải:

  • Phương pháp thế hoặc Cộng đại số (dùng cho hệ bậc nhất).
  • Đặt ẩn phụ: S = x + y và P = x·y (ĐK: S² ≥ 4P). Khi đó x, y là 2 nghiệm của phương trình t² - St + P = 0.

✏️ Bài tập mẫu & Lời giải: Giải hệ phương trình { x + y = 5 ; x·y = 6 }.
Giải: Ta có S = 5, P = 6. Vì S² - 4P = 25 - 24 = 1 > 0 nên x, y là nghiệm của t² - 5t + 6 = 0.
Giải ra được t = 2 hoặc t = 3.
👉 Hệ có 2 nghiệm (x; y) là (2; 3) và (3; 2).

4. Véc tơ

Khái niệm: Véc-tơ là đoạn thẳng có hướng. Cho a = (x₁; y₁) và b = (x₂; y₂).

Công thức trọng tâm:

  • Phép toán: a + b = (x₁+x₂; y₁+y₂) ; k·a = (k·x₁; k·y₁)
  • Tích vô hướng: a·b = x₁·x₂ + y₁·y₂
  • Độ dài véc-tơ: |a| = √(x₁² + y₁²)
  • Góc giữa 2 véc-tơ: cos(a, b) = (a·b) / (|a|·|b|)

✏️ Bài tập mẫu & Lời giải: Cho A(1; 2) và B(4; 6). Tính tọa độ véc-tơ AB và độ dài đoạn AB.
Giải: Véc-tơ AB = (xB - xA; yB - yA) = (4 - 1; 6 - 2) = (3; 4).
Độ dài đoạn AB = |AB| = √(3² + 4²) = √(9 + 16) = √25 = 5.
👉 Kết quả: AB = (3; 4) và độ dài AB = 5.

5. Hình học tọa độ

Khái niệm: Đường thẳng và Đường tròn trong mặt phẳng tọa độ Oxy.

Công thức trọng tâm:

  • Phương trình đường thẳng đi qua M(x₀; y₀) có VTPT n(A; B): Ax + By + C = 0 (với C = -Ax₀ - By₀).
  • Khoảng cách từ M(x₀; y₀) đến d: h = |Ax₀ + By₀ + C| / √(A² + B²)
  • Phương trình đường tròn tâm I(a; b) bán kính R: (x - a)² + (y - b)² = R²

✏️ Bài tập mẫu & Lời giải: Viết phương trình đường tròn tâm I(1; 2) đi qua điểm A(4; 6).
Giải: Bán kính R chính là độ dài đoạn IA.
R = IA = √[(4 - 1)² + (6 - 2)²] = √(3² + 4²) = 5.
👉 Phương trình đường tròn là: (x - 1)² + (y - 2)² = 25.

📌 CHƯƠNG TRÌNH LỚP 11

1. Hàm số lượng giác

Khái niệm: Các hàm số tuần hoàn y = sin x, y = cos x, y = tan x, y = cot x.

Tính chất trọng tâm:

  • y = sin x, y = cos x: Tập xác định D = ℝ, tập giá trị [-1; 1], chu kỳ T = 2π.
  • Hàm số chẵn: y = cos x (cos(-x) = cos x). Hàm số lẻ: y = sin x, y = tan x, y = cot x.
  • Công thức cơ bản: sin²x + cos²x = 1 ; tan x = sin x / cos x (x ≠ π/2 + kπ).

✏️ Bài tập mẫu & Lời giải: Tìm tập xác định của hàm số y = 1 / (sin x).
Giải: Điều kiện để hàm số xác định là mẫu số khác 0 ⇔ sin x ≠ 0 ⇔ x ≠ kπ (k ∈ ℤ).
👉 Tập xác định: D = ℝ \ {kπ | k ∈ ℤ}.

2. Phương trình lượng giác

Khái niệm: Phương trình chứa ẩn trong các hàm số lượng giác.

Công thức nghiệm cơ bản:

  • sin x = sin α ⇔ x = α + k2π hoặc x = π - α + k2π (k ∈ ℤ)
  • cos x = cos α ⇔ x = ±α + k2π (k ∈ ℤ)
  • tan x = tan α ⇔ x = α + kπ (k ∈ ℤ)

✏️ Bài tập mẫu & Lời giải: Giải phương trình 2sin x - 1 = 0.
Giải: 2sin x - 1 = 0 ⇔ sin x = 1/2 ⇔ sin x = sin(π/6).
👉 Nghiệm: x = π/6 + k2π hoặc x = π - π/6 + k2π = 5π/6 + k2π (k ∈ ℤ).

3. Dãy số

Khái niệm: Tập hợp các số thực được sắp xếp theo thứ tự u₁, u₂, u₃, ..., uₙ. Ký hiệu (uₙ).

Tính chất trọng tâm:

  • Dãy số tăng: uₙ₊₁ > uₙ (hoặc uₙ₊₁ - uₙ > 0) với mọi n ∈ ℕ*.
  • Dãy số giảm: uₙ₊₁ < uₙ (hoặc uₙ₊₁ - uₙ < 0) với mọi n ∈ ℕ*.
  • Dãy bị chặn: Bị chặn trên nếu uₙ ≤ M, bị chặn dưới nếu uₙ ≥ m.

✏️ Bài tập mẫu & Lời giải: Xét tính tăng/giảm của dãy số uₙ = 2n + 1.
Giải: Ta có uₙ₊₁ = 2(n + 1) + 1 = 2n + 3.
Xét hiệu uₙ₊₁ - uₙ = (2n + 3) - (2n + 1) = 2 > 0 với mọi n ∈ ℕ*.
👉 Dãy số (uₙ) là dãy số tăng.

4. Cấp số cộng

Khái niệm: Dãy số (uₙ) trong đó kể từ số hạng thứ 2, mỗi số hạng đều bằng số hạng đứng ngay trước nó cộng với một số không đổi d (công sai).

Công thức trọng tâm:

  • Công thức tổng quát: uₙ = u₁ + (n - 1)d
  • Tính chất: uₖ = (uₖ₋₁ + uₖ₊₁) / 2 (với k ≥ 2)
  • Tổng n số hạng đầu: Sₙ = n(u₁ + uₙ) / 2 = [2u₁ + (n - 1)d] · n / 2

✏️ Bài tập mẫu & Lời giải: Cho cấp số cộng có u₁ = 3 và d = 2. Tìm u₁₀ và S₁₀.
Giải: u₁₀ = u₁ + 9d = 3 + 9(2) = 21.
S₁₀ = 10 · (u₁ + u₁₀) / 2 = 10 · (3 + 21) / 2 = 120.
👉 Đáp số: u₁₀ = 21 và S₁₀ = 120.

5. Cấp số nhân

Khái niệm: Dãy số (uₙ) trong đó kể từ số hạng thứ 2, mỗi số hạng đều bằng số hạng đứng ngay trước nó nhân với một số không đổi q (công bội).

Công thức trọng tâm:

  • Công thức tổng quát: uₙ = u₁ · qⁿ⁻¹
  • Tính chất: uₖ² = uₖ₋₁ · uₖ₊₁ (với k ≥ 2)
  • Tổng n số hạng đầu (q ≠ 1): Sₙ = u₁ · (1 - qⁿ) / (1 - q)

✏️ Bài tập mẫu & Lời giải: Cho cấp số nhân có u₁ = 2, công bội q = 3. Tìm u₅.
Giải: Áp dụng công thức: u₅ = u₁ · q⁴ = 2 · 3⁴ = 2 · 81 = 162.
👉 Đáp số: u₅ = 162.

6. Xác suất

Khái niệm: Không gian mẫu Ω (tập tất cả các kết quả có thể xảy ra). Biến cố A ⊂ Ω.

Công thức trọng tâm:

  • Xác suất cổ điển: P(A) = n(A) / n(Ω) (với 0 ≤ P(A) ≤ 1)
  • Biến cố đối Ā: P(Ā) = 1 - P(A)
  • Quy tắc cộng (A, B xung khắc): P(A ∪ B) = P(A) + P(B)
  • Quy tắc nhân (A, B độc lập): P(A ∩ B) = P(A) · P(B)

✏️ Bài tập mẫu & Lời giải: Gieo một con súc sắc cân đối 6 mặt 1 lần. Tính xác suất để xuất hiện mặt có số chấm là số chẵn.
Giải: Không gian mẫu Ω = {1; 2; 3; 4; 5; 6} ⇒ n(Ω) = 6.
Biến cố A: "Số chấm là số chẵn" ⇒ A = {2; 4; 6} ⇒ n(A) = 3.
👉 Xác suất: P(A) = n(A) / n(Ω) = 3 / 6 = 0,5.

1. Hàm số & Ứng dụng đạo hàm

Khái niệm: Tính đơn điệu, cực trị, giá trị lớn nhất/nhỏ nhất (GTLN/GTNN) và tiệm cận của đồ thị hàm số.

Công thức & Lý thuyết trọng tâm:

  • Đơn điệu: Hàm đồng biến trên K ⇔ y' ≥ 0 ∀x ∈ K; Nghịch biến ⇔ y' ≤ 0 ∀x ∈ K.
  • Cực trị: x₀ là điểm cực trị khi y' đổi dấu qua x₀ (Đổi dấu từ + sang - là Cực đại, từ - sang + là Cực tiểu).
  • Tiệm cận đứng (TCĐ): x = x₀ nếu limx→x₀⁺ y = ±∞ hoặc limx→x₀⁻ y = ±∞.
  • Tiệm cận ngang (TCN): y = y₀ nếu limx→+∞ y = y₀ hoặc limx→-∞ y = y₀.

✏️ Bài tập mẫu & Lời giải: Tìm cực trị và đường tiệm cận của hàm số y = (2x - 1) / (x + 1).
Giải: TXĐ: D = ℝ \ {-1}.
• Đạo hàm: y' = [2(1) - (-1)(1)] / (x + 1)² = 3 / (x + 1)² > 0 ∀x ≠ -1.
⇒ Hàm số không có cực trị (do y' không đổi dấu).
• Tiệm cận đứng: limx→(-1)⁺ y = -∞ ⇒ Đường thẳng x = -1 là TCĐ.
• Tiệm cận ngang: limx→±∞ y = 2 ⇒ Đường thẳng y = 2 là TCN.

2. Nguyên hàm - Tích phân

Khái niệm: F(x) là nguyên hàm của f(x) nếu F'(x) = f(x). Tích phân ∫ₐᵇ f(x)dx = F(b) - F(a).

Bảng công thức nguyên hàm cơ bản:

  • ∫ xⁿ dx = xⁿ⁺¹ / (n + 1) + C (với n ≠ -1)
  • ∫ (1/x) dx = ln|x| + C ; ∫ eˣ dx = eˣ + C
  • ∫ sin x dx = -cos x + C ; ∫ cos x dx = sin x + C
  • Tích phân từng phần: ∫ u dv = u·v - ∫ v du

✏️ Bài tập mẫu & Lời giải: Tính tích phân I = ∫₀¹ (2x + eˣ) dx.
Giải: Nguyên hàm của f(x) = 2x + eˣ là F(x) = x² + eˣ.
Áp dụng công thức Newton-Leibniz:
I = F(1) - F(0) = (1² + e¹) - (0² + e⁰) = (1 + e) - (0 + 1) = e.
👉 Đáp số: I = e.

3. Mũ - Logarit

Khái niệm: Lũy thừa, hàm số mũ y = aˣ và hàm số logarit y = logₐx (Điều kiện: a > 0, a ≠ 1, x > 0).

Công thức trọng tâm:

  • logₐ(b·c) = logₐb + logₐc ; logₐ(b / c) = logₐb - logₐc
  • logₐ(bᵏ) = k·logₐb ; logₐα (b) = (1/α)·logₐb
  • Đạo hàm: (aˣ)' = aˣ·ln a ; (eˣ)' = eˣ ; (logₐx)' = 1 / (x·ln a)
  • Phương trình cơ bản: aˣ = b ⇔ x = logₐb ; logₐx = b ⇔ x = aᵇ

✏️ Bài tập mẫu & Lời giải: Giải phương trình log₂(x - 1) = 3.
Giải: Điều kiện x - 1 > 0 ⇔ x > 1.
Phương trình ⇔ x - 1 = 2³ ⇔ x - 1 = 8 ⇔ x = 9 (Thỏa mãn ĐK).
👉 Tập nghiệm: S = {9}.

4. Hình Oxyz (Hình học tọa độ Không gian)

Khái niệm: Hệ trục tọa độ Oxyz với các véc-tơ đơn vị i, j, k. Tọa độ điểm và véc-tơ trong không gian.

Công thức trọng tâm:

  • Mặt phẳng (P): Ax + By + Cz + D = 0 có VTPT n = (A; B; C).
  • Mặt cầu (S): (x - a)² + (y - b)² + (z - c)² = R² có tâm I(a; b; c), bán kính R.
  • Đường thẳng d: Phương trình chính tắc (x - x₀)/a = (y - y₀)/b = (z - z₀)/c có VTCP u = (a; b; c).
  • Khoảng cách từ M(x₀; y₀; z₀) đến (P): d(M, P) = |Ax₀ + By₀ + Cz₀ + D| / √(A² + B² + C²)

✏️ Bài tập mẫu & Lời giải: Viết phương trình mặt phẳng (P) đi qua M(1; 2; -1) và vuông góc với đường thẳng d có VTCP u = (2; 1; -3).
Giải: Vì (P) ⊥ d nên (P) nhận VTCP u = (2; 1; -3) làm VTPT n = (2; 1; -3).
Phương trình mặt phẳng (P) là:
2(x - 1) + 1(y - 2) - 3(z - (-1)) = 0
⇔ 2x - 2 + y - 2 - 3z - 3 = 0 ⇔ 2x + y - 3z - 7 = 0.
👉 Kết quả: (P): 2x + y - 3z - 7 = 0.
